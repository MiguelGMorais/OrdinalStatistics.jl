Getting started

This tutorial walks through a complete analysis: measuring education as a multidimensional construct, following Peñaloza (2012a).

The data

Education is described by seven basic functionings (Terzi, 2007). For each one, people answer: "To what extent do you feel free to achieve the benefits you value in this functioning?", on a five-point scale

no freedom ≺ low ≺ some ≺ high ≺ full freedom.

Each question is an ordinal variable with $m = 5$ categories. The relative frequencies of the answers are:

using OrdinalStatistics

functionings = ["literacy", "numeracy", "sociality", "learning",
                "physical", "science", "practical reason"]

education = [
    [0, 0, 0, 1, 0],             # literacy
    [0, 1, 0, 0, 0],             # numeracy
    [0.5, 0, 0.5, 0, 0],         # sociality
    [0.25, 0, 0, 0, 0.75],       # learning
    [0.1, 0.5, 0.1, 0.2, 0.1],   # physical activities
    [0.1, 0.6, 0.3, 0, 0],       # science and technology
    [0.3, 0.5, 0.1, 0.1, 0],     # practical reason
]

Step 1 — summarize each question

Take physical activities. Its index places it on $[0, 100]$, and its centrum names the central category:

physical = OrdinalDistribution(education[5])
ordinal_index(physical), centrum(physical)
(42.50000000000001, 3:3)

An index of 42.5 lies in the third cell of the partition of $[0, 100]$ induced by five categories, so the centrum is the 3rd category, some freedom:

index_thresholds(5)
4-element Vector{Float64}:
 12.5
 37.5
 62.5
 87.5

The Gini–Simpson variability measures how spread the answers are (0 = consensus, 1 = uniform):

gini_simpson(physical)
0.8499999999999998

Step 2 — the codual

The codual reduces the five answers to a dichotomy "low" ≺ "high" with the same variability, and gives the weight of "high". Here roughly 31 % of the population is "on track":

codual(physical)
0.30635083268962904

Step 3 — the composite index

The c-index averages the questions' indices with endogenous weights: each question's share of the total codual. Questions where people do well weigh more.

w = endogenous_weights(education)
7-element Vector{Float64}:
 0.29188249957549856
 0.0
 0.05657085118673691
 0.2523133006609953
 0.08941844679248429
 0.22914056304587255
 0.08067433873841247
cindex(education)
54.920315645922535

Step 4 — which dimensions pull the index up or down?

The contribution $Δ_q$ is how much the c-index would fall if question $q$ were removed. Positive values raise the composite index; negative values lower it.

Δ = contribution(education)
for (name, idx, wq, dq) in zip(functionings, ordinal_index.(education), w, Δ)
    println(rpad(name, 18), "index = ", lpad(round(idx; digits = 1), 5),
            "   weight = ", round(wq; digits = 3),
            "   contribution = ", round(dq; digits = 2))
end
literacy          index =  75.0   weight = 0.292   contribution = 8.28
numeracy          index =  25.0   weight = 0.0   contribution = -0.0
sociality         index =  25.0   weight = 0.057   contribution = -1.79
learning          index =  75.0   weight = 0.252   contribution = 6.78
physical          index =  42.5   weight = 0.089   contribution = -1.22
science           index =  30.0   weight = 0.229   contribution = -7.41
practical reason  index =  25.0   weight = 0.081   contribution = -2.63

Numeracy, sociality and practical reason share the same index (25) and centrum, but contribute very differently: numeracy has zero weight (everyone is concentrated in a low category), while practical reason, with a worse distribution, lowers the c-index by 2.63 points.

Working with raw survey answers

Real surveys come as one answer per respondent. Code the answers as category positions $1, \dots, m$ and use fromresponses:

answers = [4, 5, 5, 1, 4, 5, 3, 5]      # 8 respondents, 5-point scale
d = fromresponses(answers, 5)
OrdinalDistribution([0.125, 0.0, 0.125, 0.25, 0.5]; n = 8)
ordinal_index(d), nobs(d)
(75.0, 8)

Missing answers raise an error unless you drop them explicitly with skipmissing:

fromresponses(skipmissing([4, missing, 5, 2]), 5)
OrdinalDistribution([0.0, 0.3333333333333333, 0.0, 0.3333333333333333, 0.3333333333333333]; n = 3)
