The c-index

Many constructs — education, democracy, human development, business sentiment, hospital quality — have several facets, each measured by one ordinal question. The c-index (composite index) aggregates the questions' indices with endogenous weights given by the codual (Peñaloza 2012a; Peñaloza & Macedo 2012).

Definition

For a questionnaire $\mathcal{Q} = \{X_1, \dots, X_n\}$:

\[w_q = \frac{\langle\upsilon^2_q\rangle^c}{\sum_{k=1}^n \langle\upsilon^2_k\rangle^c}, \qquad \Gamma(\mathcal{Q}) = \sum_{q=1}^n w_q\, \mathcal{I}_q .\]

A question whose answers concentrate in the upper categories has a high codual and therefore a high weight: the weighting rewards performance. Questions may have different numbers of categories, because duality reduces each of them to the same lower/upper dichotomy.

Example: democratic development

Political and civil rights in 48 developing countries in 1979, both on 7-point scales (Peñaloza & Macedo 2012):

using OrdinalStatistics
political = [7, 13, 13, 5, 8, 2, 0]
civil     = [11, 12, 17, 3, 1, 4, 0]
democracy = [political, civil]

ordinal_index.(democracy)
2-element Vector{Float64}:
 33.33333333333333
 27.430555555555557
endogenous_weights(democracy)
2-element Vector{Float64}:
 0.5292643480138947
 0.47073565198610534
composite_index(democracy)
30.55468538758202

Contribution of a question

The contribution of question $q$ is the change in the c-index caused by including it, $\Delta_q\Gamma = \Gamma - \Gamma_{-q}$, where $\Gamma_{-q}$ is the c-index recomputed without $q$. It has the closed form

\[\Delta_q\Gamma = \frac{w_q}{1 - w_q}\left(\mathcal{I}_q - \Gamma\right).\]

For a question with positive weight ($0 < w_q < 1$), the contribution is positive if and only if its index exceeds the c-index, and its magnitude grows with the weight. A question with zero weight has zero contribution.

contributions(democracy)
2-element Vector{Float64}:
  3.124129832026454
 -2.7786479457513167
When a contribution is `NaN`

If a single question carries all the weight ($w_q = 1$), removing it leaves no positive weight, and its contribution is NaN.

Ambiguous coduals

If a question's codual is ambiguous (see Ambiguous cases), so is the c-index. The ambiguous keyword is forwarded to codual:

retail = [fill(0.25, 4), [0, 1, 0, 0], [0, 0, 1, 0], [0.5, 0, 0, 0.5],
          [0, 0.2, 0.8, 0], [0, 0, 0.8, 0.2], [0.2, 0, 0.8, 0], [0.1, 0.1, 0.8, 0]]
composite_index(retail; ambiguous = :lower), composite_index(retail; ambiguous = :upper)
(63.38308715704046, 61.200639923272185)

Reporting both values makes the ambiguity explicit.

Reference

OrdinalStatistics.endogenous_weights — Function
endogenous_weights(qs; ambiguous = :error, atol = √eps)

Endogenous weights of a questionnaire 𝒬 = {X₁, …, X_n} of ordinal questions: each question's share of the total codual,

\[w_q = \frac{\langle\upsilon^2_q\rangle^c}{\sum_{k=1}^n \langle\upsilon^2_k\rangle^c}.\]

qs is a collection of OrdinalDistributions or frequency vectors; questions may have different numbers of categories. The keywords are forwarded to codual. Throws a DomainError if every codual is zero.

Source: Peñaloza (2012a); Peñaloza & Macedo (2012).

source
OrdinalStatistics.composite_index — Function
composite_index(qs; ambiguous = :error, atol = √eps)

Composite index (c-index) Γ(𝒬) of a questionnaire of ordinal questions: the average of the questions' ordinal_indexes weighted by their endogenous_weights,

\[\Gamma(\mathcal{Q}) = \sum_{q=1}^n w_q\,\mathcal{I}_q .\]

The keywords are forwarded to codual.

Source: Peñaloza (2012a); Peñaloza & Macedo (2012); Peñaloza (2013).

Examples

julia> qs = [[7, 13, 13, 5, 8, 2, 0], [11, 12, 17, 3, 1, 4, 0]];  # democracy, 1979

julia> round(composite_index(qs), digits = 2)
30.55

OrdinalStatistics.contributions — Function
contributions(qs; ambiguous = :error, atol = √eps)

Contribution Δ_q Γ = Γ − Γ_{−q} of each question to the composite_index, where Γ_{−q} is the c-index without question q (weights recomputed):

\[\Delta_q\Gamma = \frac{w_q}{1 - w_q}\bigl(\mathcal{I}_q - \Gamma\bigr).\]

It is positive iff the question's index exceeds the c-index, and satisfies Σ_q (1 − w_q) Δ_q Γ = 0. Returns a vector with one entry per question; an entry is NaN when w_q = 1 (removing the question leaves no positive weight). The keywords are forwarded to codual.

Source: Peñaloza (2012a).
