The ordinal dual and codual

Theil's duality summarizes the dispersion of a long series by a dichotomy with the same dispersion. For an ordinal variable, the dual series has a lower category $y_1$ and an upper category $y_2$, $y_1 \prec y_2$, with weights $(\langle\upsilon^2\rangle, \langle\upsilon^2\rangle^c)$ summing to one:

  • the dual $\langle\upsilon^2\rangle$ is the weight of the lower category ("off track");
  • the codual $\langle\upsilon^2\rangle^c$ is the weight of the upper category ("on track").

Step 1 — isovariability: the fundamental equation

The dual series must have the same Gini–Simpson variability $\upsilon^2$ as the original one. For a dichotomy with weights $(d, 1-d)$, $\upsilon^2 = 4d(1-d)$, so $d$ solves the fundamental equation of duality

\[d^2 - d + \frac{\upsilon^2}{4} = 0, \qquad d_\pm = \frac{1 \pm \sqrt{1 - \upsilon^2}}{2}.\]

The two roots sum to one. The question is which one goes to the lower category.

Step 2 — isotonia: assigning the roots

Let $x_c$ be the centrum. Compare the mass weakly below it, $\sum_{j \le c} f_j$, with the mass weakly above it, $\sum_{j \ge c} f_j$:

SituationDualCodual
more mass below the centrum$d_+$$d_-$
more mass above the centrum$d_-$$d_+$
tie, more categories above ($m - c + 1 > c$)$d_+$$d_-$
tie, more categories below ($c > m - c + 1$)$d_-$$d_+$
tie in bothambiguousambiguous

When the centrum is a pair $\{x_c, x_{c+1}\}$, the masses compared are $\sum_{j \le c} f_j$ and $\sum_{j \ge c+1} f_j$, and the category counts $c$ and $m - c$.

Example

using OrdinalStatistics
f = [0.1, 0.5, 0.1, 0.2, 0.1]
quadratic_variability(f), centrum(f)
(0.8499999999999998, 3:3)

The roots are 0.3064 and 0.6936. The mass below the centrum, 0.7, exceeds the mass above it, 0.4, so the larger root goes to the lower category:

dual(f), codual(f)
(0.693649167310371, 0.30635083268962904)

Reduced to "low" and "high" freedom, about 31 % of the population is in the upper category.

Concentrated distributions

If all answers fall in one category, $\upsilon^2 = 0$ and the roots are 0 and 1. The masses tie, so the number of categories decides:

codual([0, 0, 0, 1, 0]), codual([0, 1, 0, 0, 0])
(1.0, 0.0)

Ambiguous cases

For $f = (\tfrac12, 0, 0, \tfrac12)$ the centrum is the pair $\{x_2, x_3\}$ and both the masses and the category counts tie: the isotonia rule cannot decide. By default this throws an AmbiguousDualError:

q4 = [0.5, 0, 0, 0.5]
try
    codual(q4)
catch err
    err
end
AmbiguousDualError{OrdinalDistribution{Float64}}(OrdinalDistribution([0.5, 0.0, 0.0, 0.5]))

Choose a root explicitly with the ambiguous keyword:

codual(q4; ambiguous = :lower), codual(q4; ambiguous = :upper)
(0.21132486540518713, 0.7886751345948129)
  • ambiguous = :lower — the codual is the smaller root;
  • ambiguous = :upper — the codual is the larger root.

The uniform distribution is not ambiguous in practice: both roots equal $\tfrac12$.

Numerical tolerance

Ties (the centrum at exactly $\tfrac12$, equal masses) are decided up to a tolerance atol, by default $\sqrt{\varepsilon}$ of the floating-point type (about $1.5 \times 10^{-8}$ for Float64). This prevents rounding errors in frequencies such as $1/3$ from breaking a genuine tie. Pass atol explicitly to change it.

Robustness

The roots have derivative $|d_\pm'(\upsilon^2)| = \frac{1}{4\sqrt{1-\upsilon^2}}$, which exceeds 1 only when $\upsilon^2 > 15/16$, i.e. near the uniform distribution. In that region small changes in the frequencies produce larger changes in the dual.

Reference

OrdinalStatistics.dual — Function
dual(d; ambiguous = :error, atol = √eps)

Ordinal dual ⟨υ²⟩ of the Gini–Simpson variability: the weight of the lower category of the dual series, a dichotomous series y₁ ≺ y₂ with weights (⟨υ²⟩, ⟨υ²⟩ᶜ) satisfying

  1. isovariability: the dual series has the same quadratic_variability variability υ² as f, so ⟨υ²⟩ is a root of the fundamental equation of duality

    \[d^2 - d + \frac{\upsilon^2}{4} = 0, \qquad d_\pm = \frac{1 \pm \sqrt{1-\upsilon^2}}{2};\]

  2. isotonia: let x_c be the centrum (for a pair centrum {x_c, x_{c+1}}, use c below and c+1 above) and compare the mass weakly below it, Σ_{j≤c} fⱼ, with the mass weakly above it, Σ_{j≥c} fⱼ:
    • if the mass below is larger, ⟨υ²⟩ = d₊;
    • if the mass above is larger, ⟨υ²⟩ = d₋;
    • on a tie, compare the numbers of categories weakly below (c) and above (m − c + 1): more categories above (respondents "off track") gives ⟨υ²⟩ = d₊, more below gives ⟨υ²⟩ = d₋;
    • if these also tie, the dual is ambiguous.

ambiguous controls the ambiguous case: :error throws an AmbiguousDualError, :lower takes the smaller root as the codual (dual d₊), :upper the larger root as the codual (dual d₋). atol is the tolerance for the centrum and isotonia ties.

The codual is 1 - ⟨υ²⟩.

Source: Peñaloza (2012a); Peñaloza & Macedo (2012).

Examples

julia> round(dual([0.1, 0.5, 0.1, 0.2, 0.1]), digits = 4)
0.6936

OrdinalStatistics.codual — Function
codual(d; ambiguous = :error, atol = √eps)

Ordinal codual ⟨υ²⟩ᶜ = 1 - ⟨υ²⟩: the weight of the upper category of the dual series. Reducing the spectrum of answers to "low" and "high" ("off track" and "on track"), it is the degree of belief of being "on track". See dual for the definition and keywords.

Source: Peñaloza (2012a); Peñaloza & Macedo (2012).

Examples

julia> round(codual([0.25, 0, 0, 0, 0.75]), digits = 4)
0.8644

julia> round(codual([0.5, 0, 0, 0.5]; ambiguous = :upper), digits = 4)
0.7887

OrdinalStatistics.AmbiguousDualError — Type
AmbiguousDualError(d)

Thrown by dual and codual when the isotonia rule cannot assign the roots of the fundamental equation to the dual categories: the masses weakly below and above the centrum tie, and so do the numbers of categories weakly below and above it (e.g. f = (½, 0, 0, ½)). Pass ambiguous = :lower or ambiguous = :upper to choose explicitly.
