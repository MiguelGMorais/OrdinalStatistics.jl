Variability

Variability is the tendency of a variable to take a wide spectrum of values. For categorical data it depends on the frequencies only: it is minimal when the distribution is concentrated in one category and maximal when it is uniform. All measures below are normalized to $[0, 1]$.

MeasureFormulaFunction
modal variability $\upsilon^\infty$$\frac{m}{m-1}\left(1 - \max_j f_j\right)$modal_variability
Gini–Simpson index $\upsilon^2$$\frac{m}{m-1}\left(1 - \sum_j f_j^2\right)$quadratic_variability
Rényi variability $\upsilon^\theta$$\dfrac{1 - \sum_j f_j^\theta}{1 - m^{1-\theta}}$renyi_variability
normalized entropy $\varepsilon$$-\frac{1}{\ln m}\sum_j f_j \ln f_j$normalized_entropy

Comparing the measures

Two series with the same modal frequency:

using OrdinalStatistics
x = [0.02, 0.10, 0.70, 0.18]
y = [0.01, 0.28, 0.70, 0.01]
modal_variability(x), modal_variability(y)
(0.4, 0.4)

The modal variability cannot tell them apart: it only looks at the most frequent category. The Gini–Simpson index and the entropy use every frequency:

quadratic_variability(x), quadratic_variability(y)
(0.6229333333333333, 0.5751999999999999)
normalized_entropy(x), normalized_entropy(y)
(0.6252893840824478, 0.5036493498685596)
Which one to use

Prefer quadratic_variability. It uses the whole distribution, has a direct interpretation — $1 - \sum_j f_j^2$ is the proportion of ordered pairs of respondents, drawn with replacement, who gave different answers — and it is the variability behind the dual and codual and the c-index.

The Rényi family generalizes the Gini–Simpson index ($\theta = 2$):

renyi_variability(x, 2) ≈ quadratic_variability(x)
true

Extreme cases

concentrated = [0, 0, 1, 0]
uniform = fill(0.25, 4)
quadratic_variability(concentrated), quadratic_variability(uniform)
(0.0, 1.0)

Reference

OrdinalStatistics.modal_variability — Function
modal_variability(d)

Modal variability υ^∞ ∈ [0, 1]:

\[\upsilon^\infty = \frac{m}{m-1}\Bigl(1 - \max_{1\le j\le m} f_j\Bigr).\]

It is 0 iff f is concentrated and 1 iff f is uniform. It ignores changes outside the modal category; quadratic_variability should usually be preferred.

Source: Souza & Peñaloza (2005), ch. II; Peñaloza (2011).

Examples

julia> modal_variability([0.02, 0.10, 0.70, 0.18]) ≈ 0.4
true
source
OrdinalStatistics.quadratic_variability — Function
quadratic_variability(d)

Quadratic variability υ² ∈ [0, 1], the normalized Gini–Simpson index (GSI), also called the nominal variance:

\[\upsilon^2 = \frac{m}{m-1}\Bigl(1 - \sum_{j=1}^m f_j^2\Bigr).\]

It is 0 iff f is concentrated and 1 iff f is uniform; 1 - Σ fⱼ² is the proportion of ordered pairs of objects (with replacement) falling in different categories.

Source: Peñaloza (2011) (nominal variance); Peñaloza (2012a) (Gini–Simpson index).

Examples

julia> round(quadratic_variability([0.02, 0.10, 0.70, 0.18]), digits = 4)
0.6229
source
OrdinalStatistics.renyi_variability — Function
renyi_variability(d, θ::Real)

Rényi variability of order θ > 1, normalized to [0, 1]:

\[\upsilon^\theta = \frac{1 - \sum_{j=1}^m f_j^\theta}{1 - m^{1-\theta}} .\]

It is 0 iff f is concentrated and 1 iff f is uniform; θ = 2 gives quadratic_variability.

Source: Souza & Peñaloza (2005), ch. II.

Examples

julia> d = OrdinalDistribution([0.1, 0.5, 0.1, 0.2, 0.1]);

julia> renyi_variability(d, 2) ≈ quadratic_variability(d)
true
source
OrdinalStatistics.normalized_entropy — Function
normalized_entropy(d)

Normalized entropy ε ∈ [0, 1], with the convention 0 ln 0 = 0:

\[\varepsilon = \frac{E}{\ln m}, \qquad E = -\sum_{j=1}^m f_j \ln f_j .\]

It is 0 iff f is concentrated and 1 iff f is uniform.

Source: Souza & Peñaloza (2005), ch. II.

Examples

julia> round(normalized_entropy([0.02, 0.10, 0.70, 0.18]), digits = 4)
0.6253
