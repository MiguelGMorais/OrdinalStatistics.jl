Ordinal distributions

An ordinal variable $(X, \prec)$ is a question whose possible answers form a finite list of categories ordered from the worst to the best, $x_1 \prec x_2 \prec \dots \prec x_m$. An observation of $X$ is a vector of relative frequencies $f \in \Delta^{m-1}$, written $(X, \prec, m, f)$. The package represents it with OrdinalDistribution.

Building a distribution

From absolute frequencies (counts). The number of observations is kept:

using OrdinalStatistics
d = OrdinalDistribution([5, 5, 50, 60, 80])   # 200 voters rating a candidate
OrdinalDistribution([0.025, 0.025, 0.25, 0.3, 0.4]; n = 200)
ncategories(d), nobs(d)
(5, 200)

From relative frequencies:

OrdinalDistribution([0.1, 0.5, 0.1, 0.2, 0.1])
OrdinalDistribution([0.10000000000000002, 0.5000000000000001, 0.10000000000000002, 0.20000000000000004, 0.10000000000000002])

From raw answers, one per respondent, coded $1, \dots, m$:

fromresponses([3, 4, 4, 5, 2, 4], 5)
OrdinalDistribution([0.0, 0.16666666666666666, 0.16666666666666666, 0.5, 0.16666666666666666]; n = 6)
Plain vectors work too

You rarely need to build an OrdinalDistribution explicitly: every measure also accepts a frequency vector, e.g. ordinal_index([5, 5, 50, 60, 80]). Building it once is useful when you compute many measures on the same data.

Validation

The constructor rejects data that cannot be a frequency distribution: fewer than two categories, negative or non-finite entries, or all-zero vectors.

try
    OrdinalDistribution([0.5, -0.1, 0.6])
catch err
    err
end
ArgumentError("frequencies must be non-negative")

Reference

OrdinalStatistics.OrdinalDistribution — Type
OrdinalDistribution(x::AbstractVector{<:Real})

An observation (X, ≺, m, f) of an ordinal variable: relative frequencies f ∈ Δ^{m-1} over m ≥ 2 categories x₁ ≺ x₂ ≺ … ≺ x_m, ordered from the worst (or lowest intensity) to the best (or highest intensity).

x may hold absolute or relative frequencies; it is normalized to sum to one. Entries must be finite, non-negative and not all zero. If x has an integer element type, it is read as absolute frequencies and the number of observations n = Σ xⱼ is stored (see nobs).

Every measure in this package accepts either an OrdinalDistribution or a plain frequency vector.

Examples

julia> d = OrdinalDistribution([7, 13, 13, 5, 8, 2, 0]);

julia> ncategories(d), nobs(d)
(7, 48)

Source: Souza & Peñaloza (2005), ch. II; Peñaloza (2012a).

OrdinalStatistics.fromresponses — Function
fromresponses(answers, m::Integer)

Build an OrdinalDistribution from raw responses, one per respondent, coded as category positions 1, …, m (1 the worst category, m the best). The absolute frequency of category xⱼ is nⱼ = #{i : answersᵢ = j}, and nobs is the number of responses.

answers may be any iterable of integers. Missing values are not dropped silently: pass skipmissing(answers) to discard them explicitly. Categories with no responses get frequency zero.

Examples

julia> d = fromresponses([4, 5, 5, 1, 4, 5, 3, 5], 5)
OrdinalDistribution([0.125, 0.0, 0.125, 0.25, 0.5]; n = 8)

julia> fromresponses(skipmissing([2, missing, 3]), 3) |> nobs
2
