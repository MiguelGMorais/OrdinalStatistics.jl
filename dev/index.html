OrdinalStatistics.jl

Location, variability, inequality and poverty measures for ordinal and categorical variables.

Ordinal data — Likert items, satisfaction surveys, rights and freedom scores, rating scales — have an order but no unit of measurement. Means, variances and the usual inequality indices are not meaningful on them. This package implements the measures that are meaningful for ordinal data, as systematized by R. Peñaloza and J. Souza: the mean charge, the centrum, the index, ordinal variability, Theil's dual and codual for ordinal variables, and the c-index, a composite index with endogenous weights.

Installation

The package is not registered yet. Install it from GitHub:

using Pkg
Pkg.add(url = "https://github.com/MiguelGMorais/OrdinalStatistics.jl")

Julia 1.10 or later is required.

Quick start

using OrdinalStatistics

# 48 developing countries, political rights in 1979 (worst → best, 7 categories)
political = [7, 13, 13, 5, 8, 2, 0]

d = OrdinalDistribution(political)
OrdinalDistribution([0.14583333333333334, 0.2708333333333333, 0.2708333333333333, 0.10416666666666667, 0.16666666666666666, 0.041666666666666664, 0.0]; n = 48)
ordinal_index(d)    # numerical location on [0, 100]
33.33333333333333
centrum(d)          # categorical location: the 3rd category
3:3
codual(d)           # weight of the "upper" category of the dual dichotomy
0.3618073004018585

Aggregate several ordinal questions into one composite index:

civil = [11, 12, 17, 3, 1, 4, 0]
composite_index([political, civil])    # democratic development index
30.55468538758202

Conventions

Categories are ordered from worst to best

Every frequency vector lists the categories in increasing order, $x_1 \prec x_2 \prec \dots \prec x_m$: the first entry is the worst (or lowest intensity) category and the last is the best. Reverse scales that run the other way before using them, e.g. with reverse(counts).

  • Frequencies may be absolute (counts) or relative (proportions); they are normalized internally.
  • Raw answers, one per respondent, are converted with from_responses.
  • Every measure accepts either an OrdinalDistribution or a plain vector.
